# The suicidality common factor

This github contains the code used to model the suicidality common factor described in the Colbert et al. 2026 medRxiv preprint, "Suicidality phenotypes reflect both shared and distinct genetic factors". The preprint can be accessed at: [https://www.medrxiv.org/content/10.64898/2026.05.14.26353207v1](https://www.medrxiv.org/content/10.64898/2026.05.14.26353207v1) 

File paths/names have been changed for privacy.
